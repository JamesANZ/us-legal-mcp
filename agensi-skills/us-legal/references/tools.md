# US legal MCP tools

Call these names. The server does not register the hyphenated names from older README headings.

| Tool | Use it for |
| --- | --- |
| `search_congress_bills` | Bills and resolutions |
| `get_recent_bills` | Recently introduced bills |
| `get_congress_committees` | Congressional committees |
| `get_bill_details` | Live metadata for a bill id such as `s1582-119` |
| `get_bill_actions` | Chronological actions for a bill id |
| `get_bill_text` | Text versions and PDF, HTML, or XML links |
| `get_public_law_text` | A GovInfo public-law package, such as `119-27` |
| `search_federal_register` | Regulations and executive orders |
| `get_recent_regulations` | Recently published Federal Register documents |
| `search_court_opinions` | Federal and state opinions |
| `get_recent_court_opinions` | Recent opinions |
| `search_all_legal` | One query across the connected collections |
| `search_digital_asset_regulation` | Congress, Federal Register, and regulator feeds scoped to digital assets |
| `get_genius_act_info` | Curated GENIUS Act record (S.1582, Pub. L. 119-27) |
| `get_clarity_act_info` | Curated CLARITY Act record (H.R.3633) |
| `get_curated_act` | Curated record by slug: `genius-act` or `clarity-act` |
| `get_recent_regulator_news` | Recent OCC, SEC, CFTC, Federal Reserve, Treasury, or FinCEN releases |
| `search_regulator_news` | Keyword search of those regulator feeds |
